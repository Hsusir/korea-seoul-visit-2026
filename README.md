# 韓國首爾參訪行程網站初稿

此網站是純靜態頁面，不需安裝套件或執行建置。開啟 `index.html` 即可預覽；上傳至 GitHub Pages 後也可直接使用。

## GitHub Pages 上線

1. 建立 GitHub repository，將本資料夾的 `index.html`、`styles.css`、`script.js` 放在 repository 根目錄。
2. 在 repository 的 **Settings → Pages**，選擇 **Deploy from a branch**，分支設為 `main`、資料夾設為 `/ (root)`。
3. 儲存後，使用 GitHub Pages 提供的網址檢視。
